# flyflyfly - 功能規格文件 (FSD)

## 1. 專案概述
flyflyfly 是一款基於 macOS 的 iOS 位置模擬工具。它允許開發者與測試人員透過 Mac 精確控制 iOS 裝置的 GPS 座標，支援定點跳轉、路徑規劃及自動巡邏等功能。

## 2. 目標使用者
*   **iOS App 開發者**：測試基於地理位置的功能（LBS）。
*   **遊戲測試員**：驗證 AR 遊戲（如 Pokémon GO）的移動邏輯。
*   **隱私保護使用者**：遮蔽真實地理位置。

## 3. 核心功能模組

### 3.1 模擬模式 (Simulation Modes)
*   **定點模式 (Fixed Point)**：一鍵修改手機位置至全球任何座標。
*   **路徑模式 (Route A-B)**：在兩點之間自動規劃路徑並模擬移動。
*   **多點模式 (Multi-point)**：自定義多個導航點，按順序執行移動任務。
*   **巡邏功能**：支援「來回巡邏」與「閉圈循環」模式。

### 3.2 裝置管理
*   **自動連線**：透過 USB 或 Wi-Fi 偵測並連線 iOS 裝置。
*   **狀態監控**：即時顯示目前裝置名稱、RSD 隧道狀態及連線日誌。

### 3.3 資料與圖層
*   **我的最愛**：儲存常用的座標與路線，支援按國家/城市自動分組。
*   **KML 導入**：支援導入第三方 KML 圖層（純點位），並提供高效的地圖渲染。

### 3.4 使用者介面 (UI)
*   **地圖中心化設計**：所有操作均環繞地圖展開。
*   **垂直摺疊側邊欄**：精簡化的控制面板，消除操作延遲。

## 4. 使用者操作流程
1.  **環境準備**：iPhone 開啟開發者模式並連線至 Mac。
2.  **建立連線**：在「裝置連線」區塊點擊「連線」，等待 RSD 隧道建立。
3.  **選擇目的地**：
    *   在地圖上點擊右鍵。
    *   或使用搜尋框搜尋地點。
    *   或從「資料與圖層」中選擇收藏。
4.  **啟動模擬**：設定速度後，點擊「開始定位」。

## 5. 非功能性需求
*   **效能**：支援 10,000+ 點位渲染不卡頓。
*   **穩定性**：斷線自動偵測與 Watchdog 保護。
*   **資源佔用**：背景運行時記憶體佔用需低於 10MB。
